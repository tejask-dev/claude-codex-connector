# Changelog

## 0.2.0 — Public preview

- First public source release with a fresh, privacy-reviewed Git history.
- MIT license, installation and recovery docs, security guidance, contribution guide and CI.
- Portable Codex executable discovery and explicit project-root configuration.
- Explicit Claude API-key setup for public Agent SDK distribution; no subscription-login fallback.
- Separate public-edition state directory; credentials remain local and owner-only.
- Optional automatic teamwork guidance; ordinary installation preserves native approval policies.
- Persistent cross-provider sessions, bounded delegation, isolated edits, drift checks, recovery and shared capability discovery.
- Desktop virtual-stream launcher with tested EOF, transport-failure and child-cleanup behavior.

Earlier local prototypes are not included in public history because their documentation and commit metadata contained machine-specific information. Historical live checks are summarized without publishing private transcripts or identifiers.
